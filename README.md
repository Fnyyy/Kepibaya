# 🐾 CapyFinder - Kepibaya Masbro & Devia Imup 🌸

Aplikasi web interaktif bertema Capybara (Masbro) santai & onsen sanctuary yang didedikasikan spesial untuk **Devia Imup** 🍊✨.

---

## 🌟 Fitur Utama

- **🍊 Masbro Radar & Jelajah Habitat**: Pantau lokasi real-time Masbro Roy, Duo Boba & Mochi, Don Fernando, Oyen Chill, dan Bimo Fam.
- **✨ Detail Profil Masbro Roy**:
  - Skor Chill-o-meter (*Level Santuy 9.9/10*)
  - Catatan & Jadwal me-time berendam onsen spesial untuk Devia
  - Bento grid stats (Umur, Cemilan Favorit, Circle Nongkrong, Hobi)
  - Fitur interaktif: *Suapi Semangka Potong 🍉*, *Elus Dagu Masbro Roy 🐾*, dan *Kirim Peluk Virtual*.
- **🌸 Edit Profil Devia**:
  - Pilihan ganti foto profil cantik Devia atau maskot chibi capybara gemoy (Yuzu, Melon, Onsen, Ranger).
  - Gelar Ranger Capy Lv. 4 & perolehan CapyHeart.
  - Sakelar kenyamanan interaktif (Sembunyikan Lokasi, Notifikasi Masbro Dekat, Mode Zen).
- **📸 Kabar Gemoy Terverifikasi & Lapor Temuan**:
  - Laporan sighting masbro terbaru dari komunitas dengan tombol *Gemes* beranimasi detak jantung.
  - Form *Lapor Temuan Masbro* untuk melaporkan capybara yang ditemui dan mendapatkan +25 CapyHeart.
- **♨️ Soundscape Zen Alami**: Audio synthesizer gemericik air hangat onsen dan denting singing bowl Tibet.

---

## 🚀 Jalankan Secara Lokal

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Jalankan dev server**:
   ```bash
   npm run dev
   ```

3. **Buka di browser**:
   ```
   http://localhost:3000
   ```

---

## ☁️ Deploy ke Vercel

Aplikasi ini sudah siap langsung di-deploy ke Vercel:

1. Import repository `https://github.com/Fnyyy/Kepibaya.git` di dashboard Vercel.
2. Vercel akan secara otomatis mendeteksi konfigurasi:
   - **Framework Preset**: `Vite`
   - **Build Command**: `vite build` atau `npm run build`
   - **Output Directory**: `dist`
3. Klik **Deploy**!
